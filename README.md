# Pharmacy POS V1
Flutter Android starter project.

Features:
- Offline SQLite database
- Dashboard
- Medicine master and stock
- Sales/cart
- Barcode scanning
- Customer due on credit sales
- Purchases database foundation
- Expenses
- Basic reports

Run:
flutter pub get
flutter run

Build APK:
flutter build apk --release

Before real-world deployment, add authentication, database backup/export, invoice PDF/printing, supplier due settlement, stock validation, audit logs, and cloud sync.
